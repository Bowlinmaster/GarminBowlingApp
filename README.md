# GarminBowlingApp
A Garmin IQ application that can be used to keep track of bowling scores.


For so long there has not been an officially supported "Bowling" activity on Garmin watches.
This is my quest to work on a simple application that you can use to keep track of your bowling games.

As a fun experiment, I am generating the majority of this app with AI generated code using ChatGPT/Copilot.  You're likely not going to find good software design principals in this application.  You can blame AI for that.
