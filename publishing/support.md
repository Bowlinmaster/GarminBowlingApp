# Bowling Stats Support

For help with Bowling Stats, search the existing reports or open a new issue at:

https://github.com/Bowlinmaster/GarminBowlingApp/issues

When reporting a problem, include:

- Garmin device model and size
- Bowling Stats version
- Device software version
- The screen or action where the problem occurred
- Steps that reproduce the problem
- A screenshot or photograph when the issue is visual

Do not include private account information, device serial numbers, or other
sensitive information in a public issue.

## Device Support Requests

Requests for an additional Garmin device should include the exact device model
and size. Device-support contributions are welcome; see the repository's
`CONTRIBUTING.md` and `BowlingStats/SUPPORTED_DEVICES.md` for the validation and
visual-baseline requirements.

## Saved Data

Bowling games and settings are stored only in the app's private storage on the
watch. Clearing saved games or uninstalling the app permanently removes that
local history. There is currently no cloud backup or recovery feature.
